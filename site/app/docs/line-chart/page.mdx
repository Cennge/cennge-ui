## When to use

Use a LineChart when the order of the values matters: days, weeks, releases, hours. The line shows the shape of a change across many points, and the crosshair gives the exact values at any one of them. Each series is a line in its own colour, named in the legend beside a sample of its stroke.

## Similar

- [AreaChart](/docs/area-chart/) is the same chart with the area under each line washed in its colour, and it can stack series into a whole.
- [BarChart](/docs/bar-chart/) takes the same `data`, `index` and `series` and compares amounts by length, from an axis that takes in zero unless you set a `domain`.
- [Sparkline](/docs/sparkline/) is a trend without axes or a readout, small enough to sit beside a number.

## A gap in the data

playwright-msi-scraper did not run over the weekend. Give `null` where there is no value: the line stops and starts again after it instead of diving to zero, and the readout and the table show a dash. A value alone between two gaps is drawn as a dot.

## Small changes, fitted axis

The value axis starts at zero by default. With `startAtZero={false}` it fits round ends around the data, which suits a rate that never leaves the nineties. `showDots` marks every value, and `axisFormat` writes the axis as `valueFormat` writes the readout.

Each dot sits in a 2px ring of the colour behind the chart, so it stays clear of the line. The ring takes `--cennge-chart-surface`, which falls back to a Card's surface; set it when the chart sits on another one, as here.

## A smooth curve

`curve="smooth"` bends through the points without overshooting them: between two equal values the curve stays flat, and a count of zero never dips below the axis.

## A trend through daily readings

Noisy readings, a build time or a body weight, read better as a trend. `movingAverage` averages each value with the six before it; give the raw values `display: "dots"` so they sit faintly under the line. A band in `references` shades the target range, from `from` to `to`.

## Accessibility

- The figure and its plot are named by `aria-label`; the plot is a focusable group described by `labels.keyboardHint`.
- Focus from the keyboard puts the crosshair on the first point. The arrows move it, Home and End jump to the ends, Escape hides it, and a polite live region reads each place, as "Oct 2: cennge-ui 10.8 min, payload-cache 4.3 min".
- The readout is for the eye only: screen readers get every value in a table captioned with the chart's name, a missing value written as a dash.
- A finger scrubs along the chart while the page still scrolls up and down; a tap leaves the readout up until a tap elsewhere.

## Server rendering

The legend, the axes, the grid and the data table come from the server. The lines are drawn once the browser has measured the plot and draw in from the left; with reduced motion they appear at once.

## Props

Each entry of `series` is `{ key, label, color }`: the field that holds its values, its name (the key without one), and a palette slot from `chart-1` to `chart-8`, a theme colour or any CSS colour.
