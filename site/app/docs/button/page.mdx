## When to use

A Button runs an action: save, publish, open a dialog. When it takes the reader somewhere instead, render a link with `asChild`, so it keeps the button's look but stays a real `<a>` that opens in a new tab and shows its address.

## Similar

- [ToggleGroup](/docs/toggle-group/) holds a state that stays pressed; a Button acts once.
- [Snippet](/docs/snippet/) is for a command to copy, not a button with code in it.

## Colours

## Loading

`isLoading` shows a spinner, sets `aria-busy` and disables the button until the request ends, so a second click cannot send it twice. The pointer stays over it with a waiting cursor.

<Example file="button/loading">

</Example>

## As a link

With `asChild` the child element is rendered with the button's styles and states. A disabled link keeps its focus, so screen readers still find it, but neither a click nor <kbd>Enter</kbd> follows it.
