## When to use

Use a Timeline for events in the order they happened: releases, deploys, the life of an issue. With `activeIndex` it tracks something under way instead, colouring the steps that are done and muting those to come.

Each `TimelineItem` has a `title`, an optional `time`, and anything you put inside it as the description. The list is an `<ol>` and every item an `<li>`, so the order is in the markup, not only on the screen.

## Similar

- [Stepper](/docs/stepper/) is a form or a task in steps that people move through and click; a Timeline only shows where things stand.
- [Table](/docs/table/) suits events you compare by column or sort; a Timeline reads top to bottom.

## Tracking progress

`activeIndex` is the index of the current item. Items up to it are done and take the `color`; the current one is `aria-current="step"`; later ones are muted, and screen readers hear ", upcoming" after their title. `lineVariant="dashed"` draws the line to the next item dashed, here for a release that has no date yet.

## Colours, icons and plans

`color` on an item overrides the timeline's, so a failed deploy can be red in a history of green ones. `bullet` puts an icon in the dot. Give an item a `dateTime` beside its `time` and the time becomes a `<time>` element that machines can read; text such as "Next week" without one stays a `<span>`.

## Horizontal

`orientation="horizontal"` lays the items out in a row, each at least 11rem wide. When they do not fit, as on a phone, the row scrolls inside itself rather than widening the page, and it is in the tab order so the arrow keys can scroll it.

## Accessibility

- Name the timeline with `aria-label` or `aria-labelledby`; it is a list, and screen readers say how many items it holds.
- Bullets and lines are decoration, hidden from screen readers. The state is in the text: `aria-current="step"` on the current item and ", upcoming" after the titles to come. `upcomingLabel` changes that word, e.g. for another language.
- A horizontal timeline has `tabIndex={0}` whether or not it overflows, so it is always one Tab stop.
