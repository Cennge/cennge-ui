## When to use

Use Kbd wherever the page tells the reader to press something: a shortcut beside a menu item, a hint under a search field, a step in a guide. One Kbd holds one shortcut, modifiers and key together, and screen readers hear it as one phrase: "Command Shift P".

## Similar

- [Snippet](/docs/snippet/) is a command to copy and paste, not a key to press.
- [Prose](/docs/prose/) styles a bare `<kbd>` from Markdown as plain text in a box. Kbd draws the symbols and names them.

## Keys and shortcuts

`keys` takes the named keys, shown in order; children add anything else, such as a letter. A key that has no name, like F5 or PageDown, is plain text. At `size="sm"` a cap fits in a line of text.

## Accessibility

A drawn symbol is `aria-hidden`; its key's full name is visually hidden text beside it, followed by a space, so <Kbd keys={["command", "shift"]} size="sm">K</Kbd> reads "Command Shift K" rather than one word. Each named key is an `<abbr>` whose `title` gives its full name on hover, Control for Ctrl and Escape for Esc. Kbd takes no focus and handles no keys: it only shows them.
