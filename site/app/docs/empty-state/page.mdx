## When to use

Show an EmptyState wherever a list can come back with nothing: the first visit before anything exists, a search with no match, a filter that leaves no rows. Say why it is empty and put the way out right under it, as a button: create the first item, clear the search.

## Similar

- [Alert](/docs/alert/) reports something that happened; an empty state describes a place with nothing in it.
- [Skeleton](/docs/skeleton/) stands in while content loads. Show the empty state only once loading is over.
- [Table](/docs/table/) takes an empty state as `emptyContent` and shows it in place of the rows.
