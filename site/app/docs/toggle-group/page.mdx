## When to use

Use a ToggleGroup for a few options that change what is on screen at once: a filter, a view, a layout. Every option stays in sight and the chosen one looks pressed. In single mode a click on the chosen item keeps it, so a segmented control always has a value.

It holds state for the page, not for a form: it takes no `name` and sends nothing on submit. For a choice that is submitted, use RadioGroup or Checkbox.

## Similar

- [Tabs](/docs/tabs/) switch between panels, each tab tied to its own content; a ToggleGroup only holds a value, and you decide what it changes.
- [Radio](/docs/radio/) is a form field with a label and a description per option, and arrows move the selection; here arrows only move focus.
- [Checkbox](/docs/checkbox/) is the form field for several independent options.
- [Button](/docs/button/) runs an action once and does not stay pressed.

## One value

In single mode `value` is the chosen item's string. Without `isDeselectable`, `onValueChange` is never called with `null`: a click on the chosen item does nothing.

## Several values

`selectionMode="multiple"` makes `value` an array of strings. Each item toggles on its own, and an empty array is a valid value.

## Allow an empty choice

With `isDeselectable`, a click on the chosen item clears it and `onValueChange` gets `null`. Here no status means every run.

## Icons only

`isIconOnly` drops an item's side padding and gives it a fixed width for one icon. With no text inside, each item needs an `aria-label`.

## Full width

`fullWidth` stretches the group to its container and gives every item an equal share. `size` sets the height and the text size.

## Accessibility

In single mode the group is a `radiogroup` and each item a `radio` with `aria-checked`. In multiple mode it is a `toolbar` and each item a button with `aria-pressed`. The group has no visible label of its own, so name it with `aria-label`.

The whole group is one Tab stop. Arrows move between items and wrap around at the ends, <kbd>Home</kbd> and <kbd>End</kbd> jump to the first and last; disabled items are skipped.

## Styling

`segmented` sits in a sunken track and fills the chosen item with `color`; `bordered` draws a border with dividers and tints the chosen item. `className` goes to the group and each item takes its own.
