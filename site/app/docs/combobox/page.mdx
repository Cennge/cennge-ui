## When to use

Reach for a Combobox when the list is long enough that people would rather type than scroll. It filters as you type, virtualizes itself past 100 options, and with `isClearable` one click returns it to the placeholder.

## Similar

- [Select](/docs/select/) is a fixed short list with nothing to type.
- [TagsInput](/docs/tags-input/) makes tags from any free text; a Combobox with `selectionMode="multiple"` only takes tags from its list.

## Pick one repository

`value` is the chosen item's `value`, or `null` when nothing is chosen. `isClearable` adds a button that sets it back to `null`.

## A thousand options

Past 100 items the list renders only the rows in view, so typing stays instant. The active option is always in the DOM, so screen readers follow it.
