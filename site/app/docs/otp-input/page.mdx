## When to use

Use an OtpInput for a short code someone copies from elsewhere: a sign-in code from an authenticator app, an email or a text message. The boxes show at a glance how long the code is and how much is left, and the field takes the code whichever way it arrives: typed one character at a time, pasted whole, or filled in by the phone's keyboard.

`onComplete` fires once every slot is filled, so the check can start without a button.

## Similar

- [PasswordInput](/docs/password-input/) is for a secret the person chose and remembers.
- [NumberInput](/docs/number-input/) is for a quantity; a code is not a number, and its leading zeros count.
- [Input](/docs/input/) fits codes of no fixed length, such as a coupon.

## Check the code when it is complete

`onComplete` gets the code as soon as the last slot is filled. Here the field is read-only while the code is checked, so focus stays in it, and a wrong one (try 000000) shows the error until the code is edited.

## Letters and hidden characters

`allowedCharacters="alphanumeric"` takes letters and digits, `alpha` only letters. `isMasked` hides each character as a password field does; `length` sets the number of slots and `groupSize` draws a separator between groups.

</Example>

## Submit when complete

With a `name`, the code goes with the form in a hidden input. `autoSubmit` sends the form as soon as the last character is in; without it, <kbd>Enter</kbd> in any slot sends it.

## Accessibility

The slots sit in a `group` labelled by the label and described by the description or the error. Each slot is named "Character 1 of 6" and so on; translate that with `formatSlotLabel`. While `isInvalid`, every slot has `aria-invalid`. The separators are hidden from screen readers.

The label is not a `<label>`, since it names a group, but a click on it still puts the caret where typing continues. `autoFocus` does the same when the field mounts.

## Styling

Each slot is the Input's box made square, with the same `variant`, `color`, `size` and `radius`. `classNames` reaches `base`, `label`, `group`, `slot`, `separator`, `description` and `errorMessage`.
