## How it works

`cennge-ui/styles.css` declares the theme as custom properties: the light theme on `:root`, the dark one on `.dark`. A Tailwind `@theme inline` block then maps them to utilities, so `bg-primary` compiles to `background-color: var(--cennge-primary)`. The utilities read the variable where the element is, at runtime: override it on `:root` and the whole app changes; override it on one element and only that part of the page does.

There is no JavaScript theme object and no provider to wrap. Light and dark are a class, the accent is an attribute, and the rest is the tokens below.

## Colour roles

Seven roles name what a colour means rather than what it is: `default`, `primary`, `secondary`, `success`, `warning`, `danger` and `info`. They are the values of the `color` prop, wherever a component has one. `primary` is the accent, `default` is neutral, and the other five are fixed: violet, green, amber, red and blue.

## Accent presets

`data-accent` swaps the accent for one of five presets: `orange`, the default, `blue`, `green`, `violet` and `red`. Put it on `<html>` for the whole page, or on any element for the part inside it. A preset sets only `primary` (its scale, fill, foreground and text) and the order of the chart palette; the other roles stay as they are. Each row below is a `<div>` with its own `data-accent`.

<Example file="theming/accents">
  <Accents />
</Example>

On orange and green the text on the fill is dark; on blue, violet and red it is white, so that every pair keeps its contrast. The site's accent switch sets `data-accent` on `<html>`, as an app would: every example on the page follows it except the rows above, which set their own.

```tsx
<html lang="en" data-accent="blue">
```

## Your own colour

To use a colour of your own, override the role's variables in your CSS, after the import. Give all eleven steps of the scale, the fill, the text on the fill, and the text colour for each theme:

```css
:root {
  --cennge-primary-50: #eef6ff; /* …through… */
  --cennge-primary-950: #0b1f3a;
  --cennge-primary: #1f6feb;            /* solid fill */
  --cennge-primary-foreground: #ffffff; /* text on the fill */
  --cennge-primary-text: #1a5fd0;       /* the colour as text, light theme */
}
.dark {
  --cennge-primary-text: #6ea8ff;       /* the colour as text, dark theme */
}
```

Check the same pairs the built-in roles meet: 4.5:1 for the foreground on the fill, and for the text colour on every surface and on the tints. Any role can be recoloured this way, not only `primary`.

The chart palette does not follow such an override: its eight slots are set by the presets, so the first keeps the preset's colour, orange by default. Set `--cennge-chart-1` in the same rule if your charts should open with your colour.

A preset of your own works like the built-in ones. Declare it under a `data-accent` value of your choosing; in the dark theme, the library already sets `--cennge-primary-text` to your 300 step on any element with `data-accent`:

```css
[data-accent="teal"] {
  --cennge-primary-50: #f0fdfa; /* …through… */
  --cennge-primary-950: #042f2e;
  --cennge-primary: #14b8a6;
  --cennge-primary-foreground: #140c06;
  --cennge-primary-text: #115e59;
}
```

The chart palette does not know such a preset either: inside it, the slots keep the order of the page around it. Set `--cennge-chart-1` to `--cennge-chart-8` in the same rule to choose your own.

## Chart palette

Series in `cennge-ui/charts` take eight colours in order, `--cennge-chart-1` to `--cennge-chart-8`, also as Tailwind's `bg-chart-1` and the like for legends of your own. The first follows the accent preset. The order after it is chosen for each preset, so that neighbours stay far apart: under violet, orange comes second and blue fourth, because violet next to blue blurs for colour-blind readers. The dots at the end of each row above show it.

The eight are checked, not picked by eye: each keeps 3:1 on every surface, and neighbours stay distinguishable under simulated protanopia and deuteranopia, in both themes and for every preset. A ninth series is grey rather than a new colour. A dot on a line sits in a ring of the colour behind the chart; off a Card, set `--cennge-chart-surface` to that colour.

## Beyond tokens

- `className` on any component is merged with tailwind-merge, so your class wins over the variant's: `<Button className="rounded-full">`.
- Components with inner parts, such as Input, Select, Dialog and Table, take classes for them through `classNames`, one key per slot: `<Input classNames={{ inputWrapper: "…" }} />`.
- `CenngeProvider` sets the default `size`, `radius` and `color` for every component below it. See [Provider](/docs/provider/).
- Light and dark are the `dark` class on `<html>`. See [Dark mode](/docs/dark-mode/).
