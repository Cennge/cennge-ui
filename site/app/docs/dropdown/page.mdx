## When to use

A Dropdown holds the actions that do not each earn a button of their own: the actions of a table row, the overflow of a toolbar, an account. Each item runs once and the menu closes behind it.

## Similar

- [Select](/docs/select/) picks a value and keeps it in its trigger; a Dropdown's items run actions and leave nothing selected.
- [ContextMenu](/docs/context-menu/) takes the same items and opens at the pointer on right click or long press; a Dropdown opens from a button that everyone can see and reach.
- [Command](/docs/command/) finds an action by typing, for more actions than fit in a short menu.
- [NavigationMenu](/docs/navigation-menu/) holds links for getting around a site; a Dropdown holds actions.

## Actions and a destructive one

`shortcut` shows a key at the right of the item. It is only a hint: binding the key is up to you. `color="danger"` keeps an item red at rest, not only when it is highlighted, and a separator sets it apart from the rest.

## An account menu

The trigger can be any single element that takes a ref and focus, here a plain `<button>` around an Avatar. `align="end"` lines the menu up with the trigger's right edge. `DropdownLabel` is a line of text above the items, not an item, so the arrows pass over it; `DropdownGroup` wraps related items in a `group`.

## Keep the menu open

An item with `keepOpen` runs and leaves the menu open, for steps people repeat, like changing the text size one pixel at a time. The label above the items shows the size as it changes.

## An item that opens a dialog

Keep the Dialog outside the menu, open it from `onAction`, and set `isModal={false}` on the Dropdown so the menu and the dialog do not both hold the page. By the time the dialog closes, the item that opened it is gone, so `onCloseAutoFocus` sends focus back to the menu's button.

## Accessibility

The trigger gets `aria-haspopup="menu"` and `aria-expanded`; the menu and its items have the roles `menu` and `menuitem`, and a disabled item is `aria-disabled`. While a modal Dropdown is open, the rest of the page is hidden from screen readers and ignores the pointer, so the menu is all there is until it closes.

## Styling

`DropdownContent` is at least 13rem wide and never taller than the room between the trigger and the edge of the window; a longer menu scrolls. Its `className` and each item's `className` are merged last, so they win over the defaults.
