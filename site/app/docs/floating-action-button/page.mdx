## When to use

Use one FloatingActionButton on a screen with one obvious action: log a meal, add a workout, start a run. If the action needs a choice first, let it open a [Dropdown](/docs/dropdown/) or a bottom [Drawer](/docs/drawer/) of the options, the most frequent first. Not every screen needs one; never use two.

## Similar

- [Button](/docs/button/) sits in the flow of the page with the rest of its content.
- [BottomBar](/docs/bottom-bar/) gives an action a full row with its label, for a screen where it repeats every few seconds.

## Extended, large, in colour

`isExtended` shows the label beside the icon; fold it away as the page scrolls and bring it back at the top. `size="lg"` makes a 96px button for a screen with nothing else to do, and `color` takes a theme colour.

## Fixed to the screen

`position="fixed"`, the default, places it 16px from the right edge and above whatever is fixed to the bottom: a [BottomNavigation](/docs/bottom-navigation/), a [BottomBar](/docs/bottom-bar/), and the home indicator. `position="static"` leaves it where you put it, as on this page.

## Accessibility

Its name is its `label`, given as `aria-label` while only the icon shows and as visible text once extended, so it is the same either way. The icon is hidden from screen readers. As a trigger it forwards its ref, so a Dropdown or a Drawer opens from it and gives focus back to it.
