## When to use

Use Progress for a task with an end: an upload, a clone, a run of CI jobs. `Progress` is the bar for a row or a form; `CircularProgress` is the ring for a tile or a tight corner. Until you know how much is done, leave `value` out: both still say that work is under way.

## Similar

- [Spinner](/docs/spinner/) is a small turning ring with no value and no progressbar role, sized to sit in a line of text.
- [Skeleton](/docs/skeleton/) stands in for content whose shape you already know.
- [Stepper](/docs/stepper/) counts named steps a person moves through, not the share of a task that is done.

## Any scale, any text

`value` counts up to `max`, 100 unless you set it. With a label the value shows beside it, as `formatValue` writes it, and screen readers read the same text. Without a visible label, name the bar with `aria-label`.

## Still working

Leave `value` out, or pass `null`, while the amount is unknown. Pass a number once it is, and the bar or ring changes in place.

## Circular

Four sizes, from 32 to 96 pixels. `showValue` puts the value in the middle; the `label` sits under the ring and names it for screen readers. `strokeWidth` changes the thickness of the ring.
