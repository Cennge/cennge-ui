New entry `cennge-ui/map`: `Map`, `MapMarker`, `MapPopup`, `MapControls` and `MapRoute` on MapLibre GL, an optional peer dependency fetched only when a map mounts. OpenFreeMap tiles by default (no key), light and dark with the page; markers and popups are accessible buttons and dialogs in the library's style; routes take the accent colour. See the README for the one-line worker setup.
